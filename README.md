# MV PROTECT

Site vitrine MV PROTECT — detailing automobile, PPF, traitement céramique, polissage et covering à Basse-Ham.

## Structure

- `artifacts/mv-protect` : frontend React/Vite
- `artifacts/api-server` : API Express/Node.js
- `lib` : bibliothèques partagées

## Développement

```bash
pnpm install
pnpm --filter @workspace/mv-protect run dev
```
